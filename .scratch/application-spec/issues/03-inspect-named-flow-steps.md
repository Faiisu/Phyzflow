# 03: Inspect a flow step by step

**What to build:** A developer can follow named steps in a Python flow from the web UI and identify where an error began.

**Blocked by:** [01: Create a Workspace and run its first flow](01-create-and-run-a-workspace.md)

**Status:** ready-for-agent

**Spec requirements:** FLOW-01, FLOW-02

- [ ] Run a flow with multiple connected named steps. Inspect each step's status, timing, and place in the flow.
- [ ] Publish progress and a metric from within a step. Verify that both appear in the UI while that step runs.
- [ ] Force a step to fail and verify the UI identifies that step and its error.
